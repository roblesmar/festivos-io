# festivos 🇪🇸

**Spain's public holidays — national, regional _and local (per municipality)_ — as an open dataset, with an official source behind every single holiday.**

[![Code: MIT](https://img.shields.io/badge/code-MIT-blue.svg)](LICENSE)
[![Data: CC BY 4.0](https://img.shields.io/badge/data-CC%20BY%204.0-green.svg)](LICENSE-DATA)
[![Coverage: 2024–2026](https://img.shields.io/badge/coverage-2024–2026-orange.svg)](#coverage)
[![Municipalities: 8,132](https://img.shields.io/badge/municipalities-8%2C132-lightgrey.svg)](#coverage)

Spain's working calendar has **four levels**: national → regional (_autonómico_) → **local / municipal**. The last one is the largest and the one that actually drives payroll, HR, logistics and real business closures: each of the **~8,132 municipalities** sets **2 local holidays** of its own every year (~16,000 local holidays/year). Almost every dataset stops at the regional level. **This one doesn't.**

| Project | Spain subdivisions | Municipal local holidays? |
|---|---|:---:|
| Nager.Date | Regions only | ❌ |
| OpenHolidays API | Regions + provinces | ❌ |
| date-holidays | Regions + some islands | ❌ |
| python-holidays | Regions only | ❌ |
| **festivos** | **Regions + province + municipality (INE code)** | ✅ |

Every holiday carries a **source**: national and regional holidays cite the official BOE entry (`ref` + `url`); local holidays name their regional gazette. So the calendar is traceable to official sources — and correctable by Pull Request.

## What you get

- **8,132 municipalities**, years **2024–2026**, all 17 regions + Ceuta & Melilla.
- Three levels per municipality: `national` · `regional` · `local`.
- **Canonical key = INE code** — a 5-digit string, e.g. `"43148"` for Tarragona.
- Multilingual holiday names (`es`, `ca`, `eu`, `gl`, `ca-valencia`).
- Both **JSON** and **`.ics`** per municipality (subscribe it in Google/Apple Calendar).
- A `source` on **every** holiday — with the official `url` for national and regional (BOE) ones.

## Quick start

**1. Grab a municipality's holidays** (hosted, free):

```bash
# Tarragona (INE 43148), 2026 — JSON
curl https://festivos.io/v1/2026/municipio/43148.json

# the same, as a calendar feed
curl https://festivos.io/v1/2026/municipio/43148.ics
```

**2. Subscribe in your calendar** — add this URL as a subscribed calendar in Google/Apple Calendar:

```
https://festivos.io/v1/2026/municipio/43148.ics
```

**3. Ask the query API:**

```bash
# Is 2026-08-19 a holiday in Tarragona?  → { "holiday": true, "name": "San Magín", ... }
curl "https://api.festivos.io/v1/is-holiday?date=2026-08-19&municipio=43148"

# long weekends (puentes) for the year
curl "https://api.festivos.io/v1/puentes?municipio=43148&year=2026"
```

**4. Use it from an AI agent (MCP)** — a remote MCP server exposes these as tools for assistants like Claude:

```
https://mcp.festivos.io
```

…or self-host it from [`mcp/`](mcp/).

## Coverage

| Level | Status |
|---|---|
| **National** (BOE) | 2024–2026 |
| **Regional** — 17 CCAA + Ceuta & Melilla (BOE) | 2024–2026 |
| **Local** (per municipality) | 2024–2026 · **~88% of municipalities have their local holidays in 2026** |
| Formats | JSON + `.ics` per municipality; regional & national bundles |

The remaining municipalities are ones whose town council hasn't published (or hasn't published in a machine-readable way) — those gaps close by ingestion and by community PRs.

## Build it yourself

The dataset is generated by a small Python pipeline — no framework, just `openpyxl` + `rapidfuzz`:

```bash
pip install -r ingest/requirements.txt

# reference tables (INE municipalities ↔ province ↔ region)
PYTHONPATH=ingest python3 -m festivos.cli ref 2026

# one region's local holidays (e.g. Catalonia)
PYTHONPATH=ingest python3 -m festivos.cli local ES-CT 2026

# one municipality
PYTHONPATH=ingest python3 -m festivos.cli municipio 43148 2026

# the whole year → writes v1/2026/
PYTHONPATH=ingest python3 -m festivos.cli build 2026
```

Each region has its own parser in [`ingest/festivos/fuentes/`](ingest/festivos/fuentes/) that reads the official gazette or open-data portal. The 19-source map is in [INGESTA-LOCALES.md](INGESTA-LOCALES.md).

## Repository layout

```
ingest/     Python pipeline — 19 regional parsers, INE matching, JSON/ICS writers
schema/     JSON Schema for every published file
data/       canonical curated data (regional & local holidays, school & tax calendars)
v1/ref/     reference tables (INE municipalities, regions, attribution)
mcp/        remote MCP server — holidays as tools for AI agents
examples/   sample built files (Tarragona 2026, JSON + ICS)
```

> The full generated dataset (`v1/2026/…`, ~300 MB) is **not** committed — it's reproducible with the pipeline above and served live at `festivos.io/v1/…`.
